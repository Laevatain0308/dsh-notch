# 0.3.0 — Decisions in motion

Running tasks now travel into yellow decisions with the same brush motion used for green success and red failure. Answered decisions return to the running orbit, preserving task counts for both one-task and concurrent-task cases. Fast replies wait for the outgoing stroke; cancelled requests cannot reopen an old question.

The recording demo contains 36 scenes with Chinese and English state titles. It builds directly from the production Swift animation sources, uses a local transport stub, and never connects to DSH or calls a model. Grid, single-scene, replay and fullscreen controls are documented in `tools/recording/README.md`.

This release also includes the current Markdown question rendering and robot alignment refinements, repairs capped long-question scrolling, and includes the previously ignored source needed by the legacy `--demo` build.

Validation on macOS:
